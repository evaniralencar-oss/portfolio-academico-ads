
## Projeto em Java: Simulador de Financiamento

Projeto acadêmico em desenvolvimento que permite ao usuário escolher um tipo de financiamento:

- Casa
- Apartamento
- Terreno

Após a escolha, o sistema realiza os cálculos de acordo com o tipo de financiamento selecionado.

## Tecnologias e conceitos praticados

- Java
- Programação orientada a objetos
- Classes e métodos
- Entrada de dados pelo usuário
- Condicionais
- Organização de código

## Status

Em desenvolvimento - primeira etapa da atividade acadêmica.
