Gestor de Portfólio Pessoal em Python

Projeto acadêmico concluído desenvolvido para gerenciar projetos pessoais por meio do terminal.

O sistema permite cadastrar, listar, atualizar e remover projetos. As informações são salvas em um arquivo JSON, permitindo manter os dados após o encerramento do programa.

## Funcionalidades

- Adicionar novos projetos
- Listar projetos cadastrados
- Atualizar nome e status de um projeto
- Registrar histórico de alterações com data e hora
- Remover projetos
- Salvar os dados em arquivo JSON
- Validar entradas inválidas do usuário

## Tecnologias e conceitos praticados

- Python
- Funções
- Listas e dicionários
- Estruturas condicionais e laços de repetição
- Tratamento de exceções
- Manipulação de arquivos JSON
- Biblioteca `datetime`
- CRUD: criar, consultar, atualizar e remover dados

## Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Execute o arquivo principal:


python nome_do_arquivo.py
